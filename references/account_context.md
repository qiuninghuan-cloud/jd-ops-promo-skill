## 四、已确认的结构性问题

1. **客单价 ¥27.25（上期 ¥32.28，-15.6%）**：订单量 +15.55% 但成交额 -2.45%。
   - 根因①：中价品被**长期促销价**砍 20–40%（紫草膏 -40%、苯甲酸 -34%、硼酸 -28%）；只有 ¥58 两款几乎没降（到手 ¥55）。**注意：双 11 立减已于 10-13 退出且价格未回升，证明折扣源是常驻促销价。**
   - 根因②：走量三件套（鱼石脂 ¥11.47 / 白虎膏 ¥10 / 风精油 ¥10，合计 16 万+ 评价）占绝对单量。
   - 根因③（10-13 新增）：**主力智能计划 47 个 SKU 混投，当日约 75% 广告费（¥880+）流向池外下柜品**；池内预算又压在 ¥10–11 走量品上（鱼石脂当日 ¥279.91），¥55 两款仅得 ¥43.82 且 CPC 15.09；智能计划无法否词。
2. **加购率 70.69% vs 转化率 9.48%**：61pp 流失在最后一步 → DMP「加购未购」人群收割 + 加购券。
3. **CPC–客单价错配**（按到手价、CVR 参考同品类估算）：
   | 品          | 到手价    | 估算 ROI   |
   | ---------- | ------ | -------- |
   | 白虎膏        | ¥10    | 0.58     |

   | 苯甲酸        | ¥25    | 1.00     |
   | 硼酸维E ×2    | ¥28    | 1.12     |
   | 紫草膏        | ¥30.89 | 1.24     |
   | 苗草癣 / 肤毒蝳净 | ¥55    | **1.65** |
   | 苗草癣 2 盒装   | ¥110   | 2.20     |

   → 低价品在当前 CPC 下必亏，**多卖高价品是账户投产的唯一解药**。预算建议（10-13 更新）：全店推广 ROI 1.92 且预算没跑满 → 提到 2,000–2,500/日；主力计划维持 3,500 但**砍掉 CPC>3 或后台 ROI<1 的 SKU 单元**（槐实 0 单/手足 0.65/炉甘石 1.09 高 CPC）；苗草癣全站智能 CPC 15.09 必须降出价；走量品压到 ¥700–800/日且 CPC ≤1.2–1.3。
4. **预算平移别删老计划重建**（会重置学习期），新建「高价品主推计划」单独跑。
5. **在投商品标题违规清单**（创意审核风险 + 不能作为上柜标题）：硫磺膏「阴虱/私处/阴囊」、槐实膏「痔疮/外痔/内痔/混合痔」、水杨酸「去黑头/去角质/粉刺/闭口」、炉甘石「舒缓/婴儿」、手足脱皮膏「水泡/疹」、风精油「防瞌睡/晕车」、清凉油「万金油」；在售标题中漱口水含「杀菌/抗菌」红线词（当天改）；紫草膏与漱口水两条 SPU 标题品牌词为「津鹏」，与店铺主品牌「周郎中」不一致，需统一。
