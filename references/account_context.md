## 四、已确认的结构性问题

1. **客单价 ¥27.25（上期 ¥32.28，-15.6%）**：订单量 +15.55% 但成交额 -2.45%。
   - 根因①：全店挂「官方直降·立减 15%」，中价品被砍 20–38%（紫草膏 -38%、苯甲酸 -34%、硼酸 -28%）；只有 ¥58 两款几乎没降（到手 ¥55）。
   - 根因②：走量三件套（鱼石脂 ¥11.47 / 白虎膏 ¥10 / 风精油 ¥10，合计 16 万+ 评价）占绝对单量。
2. **加购率 70.69% vs 转化率 9.48%**：61pp 流失在最后一步 → DMP「加购未购」人群收割 + 加购券。
3. **CPC–客单价错配**（按到手价、CVR 参考同品类估算）：

   | 品 | 到手价 | 估算 ROI |
   |---|---|
   | 白虎膏 | ¥10 | 0.58 |
   | 鱼石脂 ×2 | ¥11.47 | 0.67 |
   | 苯甲酸 | ¥25 | 1.00 |
   | 硼酸维E ×2 | ¥28 | 1.12 |
   | 紫草膏 | ¥30.89 | 1.24 |
   | 苗草癣 / 肤毒蝳净 | ¥55 | **1.65** |
   | 苗草癣 2 盒装 | ¥110 | 2.20 |
   | 苗草癣 3 盒装 | ¥165 | 2.75 |
   | 苗草癣 17 盒装 | ¥580 | **5.80** |

   → 低价品在当前 CPC 下必亏，**多卖高价品是账户投产的唯一解药**。预算建议：高价品计划 ¥1,500/日（CPC 2.5–3.5），走量品压到 ¥700–800/日且 CPC 必须 ≤1.2–1.3。
4. **预算平移别删老计划重建**（会重置学习期），新建「高价品主推计划」单独跑。
