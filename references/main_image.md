# 主图优化 SOP（CTR 导向）

> 主图是**供应商少数能完全自主优化的资产**（标题有字符限制、前台价改不了、推广结构受采销约束）。
> 主图点击率（CTR）在京东同时影响两件事：**快车的点击成本**（CTR 高→质量分高→同样排名更便宜）和**自然流量分配**。
> 本文件只讲"怎么让图被点得更多"，模板见 `assets/title_template.md`，成品见 `examples/detail_page_sample.md`。

## 〇、主图前先想清楚：用户在哪看到你的图

| 场景 | 出现位置 | 用户状态 | 主图策略 |
|---|---|---|---|
| **搜索** | 搜索结果列表 | 主动找解决方案，横向比价 | **白底 + 产品主体大 + 卖点字**，3 米外能认出是什么 |
| **推荐** | 首页推荐/购物触点/逛 | 闲逛，无明确意图 | **场景 + 氛围 + 利益点**，让人停下来 |

首图（主图1）以搜索场景为准——大部分消字号流量来自搜索。

## 一、京东主图技术规范（不达标直接卡审）

| 项 | 规范 |
|---|---|
| 首图尺寸 | 800×800 px，正方形，白底（纯白 #FFFFFF），主体占画面 60–80% |
| 图片格式 | JPG/PNG，单张 ≤ 500KB（超了加载慢，跳失率高） |
| 第 2–5 张 | 可放场景图/卖点图/细节图，不强制白底 |
| 主图视频 | 30 秒内，竖版优先，前三秒必须出现产品主体（自动播放时静音，前 3 秒定生死） |
| 长图 | 竖版详情页用，宽 750px，单屏高 ≤ 1200px |

## 二、五张主图的分工（按转化任务排，不是按卖点平铺）

| 图序 | 转化任务 | 画面要点 | 文案要点 |
|---|---|---|---|
| **1 首图** | 让人在列表里点你 | 白底 + 产品 45° + 品牌角标；**不放超过 2 行字** | 品名 + 规格（30g）+ 核心词（外用抑菌） |
| **2 卖点图** | 回答"凭什么" | 成分/容量特写，数字放大 | 一个数字卖点优先：30g 大容量 / 草本配方 |
| **3 场景图** | 让人看到自己 | 真实使用场景（手/居家），不用病患/病灶 | 场景词：居家 / 外出 / 家庭常备 |
| **4 对比图** | 加速决策 | 客观对比（30g vs 20g 容量），**禁拉踩竞品** | 客观陈述差异，不用"最/第一" |
| **5 信任图** | 消除最后顾虑 | 消字号资质角标 + 组合装/多件装信息 | 家庭囤货更划算 + 行动引导 |

> 单图文案 ≤ 12 个汉字是铁律。超过就拆到下一张，别把首图变成海报。

## 三、CTR 优化六手法（按见效速度排）

1. **数字具体化**："30g 大容量"比"大容量更耐用"点击率高——具体数字本身就是说服力。
2. **利益点前置**：用户搜"皮肤抑菌膏"，首图第一眼要看到"抑菌"相关词，别把品牌放最大。
3. **大字报对比**：第 4 张对比图用"30g vs 20g"的容量数字对比，比文字罗列有效。
4. **场景代入**：第 3 张放真实使用场景（涂抹的手部特写），推荐流量场景这张决定停留。
5. **信任背书**：消字号资质角标放第 5 张——消字号品类用户对"是不是正规产品"高度敏感。
6. **留白与对比**：白底首图上产品和背景对比要强；深色产品配纯白底，浅色产品加浅灰投影。

## 四、竞品对标 SOP（30 分钟，做新品/改版前必做）

1. 京东搜核心词（如"皮肤抑菌膏""紫草膏"），截图**前 10 名主图**（PC + APP 各截一次，展示逻辑不同）。
2. 拆解共性：他们首图都放了什么字？用了什么颜色？产品角度？——**共性 = 用户已被教育出的预期，你要在共性里做差异化**。
3. 找 1 个差异点做自己的记忆点（如：别人都放单支，你放"30g 大容量"数字牌）。
4. 记录对标结论进 `references/account_context.md` 的竞品栏，改版时不用重新截。

## 五、测图方法（改完必须验证，不许"我觉得"）

- **京东官方**：部分类目有"主图测试/测图"工具，同 SKU 多图轮播，看 CTR 数据。
- **手动替换法**（通用）：换图后观察 **3 天**搜索 CTR（商智→商品→流量分析），CTR 提升 > 15% 保留，否则回滚。
- **注意**：一次只换一张图。同时换 3 张，数据归因就废了。

## 六、消字号主图视觉红线（比文案红线更容易被忽略）

| 禁止 | 原因 |
|---|---|
| 使用前后对比图 | 暗示疗效，消字号一票否决 |
| 皮肤病灶/患处特写 | 医疗暗示，审核下架高发区 |
| 医生/白大褂/听诊器元素 | 暗示医疗行为 |
| "秒杀/痊愈/根除"式字样 | 绝对化 + 疗效双重违规 |
| 医疗符号（十字、处方标志 Rx） | 消字号不是药，出现即敏感 |

## 七、常见扣分项（京东主图质量分）

- 牛皮癣（边框、满图水印、多行堆字）
- 首图非白底 / 主体占比 < 40%（列表里看不清是什么）
- 图片拉伸变形、模糊、压缩失真
- 主图与详情页/标题承诺不一致（用户预期落差 → 差评）

## 八、文案速查

主图文案没有 45 字符限制，但受同一套禁用词约束。校验方式：

```bash
python3 "$SKILL_DIR/scripts/check_title.py" "主图文案" --max 100   # 忽略字符数警告，只看禁用词命中
```
