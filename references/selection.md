# 选品模块（周郎中 · 京东自营供应商视角）

> **身份前提**：我们是京东自营的**供应商**，不是店铺运营方。
> 选品落地方式 ≠ 自己上新，而是：**设计 SKU 结构 → 测算供货价与毛利 → 向采销提报 → 采销定价上柜**。
> 先确认商品前台价与活动资源的实际权限，需采销处理的准备提报；不要把某账户历史分工当所有供应商的固定权限。

---

## 一、选品的四个筛子（按顺序过，任一不过就放弃）

| 筛子 | 判断标准 | 数据来源 |
|---|---|---|
| **① 合规准入** | 消字号资质齐全（卫消证字）、宣称不越界、成分无违禁 | 资质文件 + `xiaohaohao_compliance.md` |
| **② 市场容量** | 类目月搜索量、月销规模是否撑得起目标 | 京东商智 → 行业分析 / 搜索分析 |
| **③ 竞争度** | TOP10 销量集中度、价格带空隙、评价数门槛 | 商智 → 竞品分析 / 商品销售排行 |
| **④ 毛利结构** | 供货价、毛利率、能否覆盖广告与物流 | 内部成本表（**当前数据缺口**） |

> **合规是一票否决**：标题/主图能改，资质选错就是下架 + 扣权重。
> 消字号逆向清单（选品阶段就排除）：宣称治疗/消炎/抗菌/修护/湿疹/皮炎/痔疮/脚气/痤疮的品类方向，以及需要药品/器械资质的品类。

## 二、京东商智：选品该看哪些数

| 维度 | 看什么 | 怎么用 |
|---|---|---|
| 行业分析 | 类目 GMV 趋势、环比、子类目占比 | 判断赛道在涨还是在退 |
| 搜索分析 | 关键词搜索人气、点击率、转化指数、蓝海词 | **蓝海词 = 搜索人气高但在线商品少** → 选品与埋词方向 |
| 商品分析 | TOP 商品销量/价格/评价数 | 找价格带空隙与评价门槛 |
| 竞品分析 | 竞品流量结构（搜索/推荐/活动占比） | 判断进入难度：若竞品 70% 流量来自活动，说明自然位难抢 |
| 属性分析 | 规格/容量/成分的销售占比 | 定 SKU 规格（20g / 30g / 多件装） |

**快速判断法**：打开类目前 20 名，看三件事——
1. 价格带是否有一个明显空档（如主流 20g/¥39，而 30g/¥49.8 无人做 → 容量差异化机会）
2. TOP 商品评价数门槛（若普遍 5 万+，新品硬刚代价大 → 走细分词）
3. 规格集中在哪（若全是单支装，多件装就是结构性机会）

## 三、SKU 结构设计（供应商唯一能自主拉的杠杆）

> 前台价改不了，但**一个订单里我方商品的件数与规格**是可以设计的——这是供应商提高单笔收入的核心手段。

| SKU 类型 | 作用 | 周郎中可落地动作 |
|---|---|---|
| **引流单品** | 低门槛拉新、冲评价 | 鱼石脂 ¥16.5、白虎膏 ¥12、风精油 ¥10（已有） |
| **主力单品** | 承接搜索、稳定转化 | 苗草癣 ¥58、肤毒蝳净 ¥58、紫草膏（前台 ¥30.89） |
| **多件装** | **提高单笔我方金额** | 苗草癣 / 肤毒蝳净 上架 **2 盒装 / 3 盒装**（肤毒蝳净现仅 1 个 SKU，必须补） |
| **组合装** | 关联动销、拉高件单价 | 紫草膏 + 硼酸维E、膏 + 油（家庭护理装） |
| **囤货装** | 大客单、极高投产 | 苗草癣 17 盒装 ¥580（状态「可上柜」，零成本上架） |

**设计原则**
1. 多件装是独立SKU，按真实装数、供货条件与成本测算；消费者购买不等于京东当期采购或即时回款，不能直接宣称供货收入翻倍。
2. 多件优惠必须按**件数**设门槛（第 2 件半价 / 满 2 件减）。**按金额设会漏给别家商品**（自营大店里凑单的是别的供应商）。
3. 组合装定价必须 ≥ 单品之和 × 折扣底线，**先算毛利再定让利幅度**。

## 四、供应商选品落地流程（自营）

```
1. 选品立项（市场 + 合规 + 毛利三筛）
        ↓
2. 设计 SKU 结构（单支 / 多件装 / 组合装 + 建议售价区间）
        ↓
3. 成本核算：生产成本 → 供货价 → 供货价率 → 毛利率
        ↓
4. 提报采销（附市场数据、竞品对标、建议售价、预估销量）
        ↓
5. 采销定价、上柜 → 商品进入「在售池」→ 才可做标题/主图/推广
        ↓
6. 上架后 30 天：新品推广 + 手动精确词跑转化样本 → 评价积累 → 放量
```

> 当前加投限已核实在售商品；下柜历史消耗保留对账，未上架商品可做新品立项，不冒充当前可投。状态未知标待核实。

## 五、新品上市 30 天节奏

下表是历史排期示例，不是平台权重规则或新品固定投法；实际投放方式、样本、观察期和预算按 `operator_judgment.md` 与 `business_workflows.md` 的新品分支选择，不能为凑点击或复制计划扩大消耗。

| 阶段 | 动作 | 指标 |
|---|---|---|
| D1–7 冷启动 | 快车新品推广 + 手动精确词（**不要一上来开智能**）；主图/详情/标题到位 | 点击 ≥30/日，出首单 |
| D8–15 权重期 | 积累转化样本；补评价（晒图/视频）；微调出价 | 关键词 ≥10 点击激活，CVR 达类目均值 |
| D16–30 放量期 | 多计划复制扩量（A 计划 50 → 新建 B 计划 50，**不要单计划直加 10 倍**） | ROI 波动 <20% 说明模型跑稳 |

## 七、选品红线

- ❌ 不选需要药品/医疗器械资质而我们只有消字号的品类方向。
- ❌ 不选宣称必然越界的品类（治疗、消炎、抗菌、修复类诉求）。
- ❌ 不为凑 SKU 数而上新品——每多一个 SKU 就多一份库存与广告分摊压力。
- ❌ 不在未拿到供货价/毛利率前定多件装的让利幅度（会卖越多亏越多）。
- ❌ 下柜/未上架商品不进选品推荐清单。
