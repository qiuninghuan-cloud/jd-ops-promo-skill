# 京东标题与搜索优化（SEO）规范 · 详版

本文件指导 skill 为周郎中商品生成高搜索权重、合规、可直接复制使用的京东标题。京东专属框架参考开源 skill `marketing-china-ecommerce-operator` 的京东最佳实践，并按消字号场景做合规裁剪。

> **口径统一**：京东标题建议 **≤ 45 字符（约 30 个汉字，含空格/标点）**。`scripts/check_title.py` 默认 `--max 45` 即按此校验。历史文档写的"30 汉字"与"45 字符"是同一约束的两种表述，以字符数为准。

---

## 一、标题结构公式（京东专用）

京东搜索算法对**品牌权重**与**规格精准度**敏感，标题以"品牌 + 商品名 + 关键规格 + 合规功效/成分 + 使用场景"为主：

```
[品牌词] + [商品名/核心词] + [关键规格] + [合规功效词/成分词] + [使用场景/人群词]
```

**各槽位说明**

| 槽位 | 必填？ | 作用 | 写法要点 |
|---|---|---|---|
| 品牌词「周郎中」 | 必填、前置 | 吃品牌搜索 + 品牌专区，防被竞品截流 | 固定放第 1 词 |
| 商品名/核心词 | 必填 | 命中品类搜索（抑菌膏/紫草膏） | 用用户真实叫法，如"紫草皮肤抑菌膏" |
| 关键规格 | 必填 | 京东用户重参数，提升精准度与转化 | 30g 必须写，不要只写"大容量" |
| 合规功效/成分词 | 建议 | 强化功效心智（只能抑菌/清洁/护理） | 抑菌/草本/植物配方，不堆砌 |
| 场景/人群词 | 建议 | 覆盖长尾搜索 | 家庭常备/居家外出/成人 |

示例（紫草皮肤抑菌膏）：
`周郎中 紫草皮肤抑菌膏 30g 草本植物配方 外用抑菌 家庭常备`

- 淘宝式"属性+卖点+人群"长公式在京东不必照搬，京东**更短更精准更好**，堆词反而稀释权重。
- 词块用**半角空格**分隔，利于京东分词引擎切词命中。

## 二、关键词研究方法（生成标题前先做这步）

不要凭感觉填词，按 4 个来源挖真实词：

1. **京东搜索下拉框**：在京东搜索框输入核心词（如"紫草""抑菌膏"），记录自动补全的长尾词——这些是高意图词。
2. **竞品标题拆解**：搜同类 Top 商品，拆其标题高频词块（品牌/规格/功效/场景），取其合规部分借鉴。
3. **京东商智（自营）/京麦数据（POP）**：看"搜索词分析""行业热词"，取有展现且竞争适中的词。
4. **用户问大家/评价**：真实用语（"能不能随身带""大人能用吗"）转成场景词。

**筛选标准**：① 真实搜索量 > 0；② 不与禁用词冲突；③ 与本品相关（不蹭无关病种词）。

## 四、埋词策略

- **核心词前置**：前 15 字内出现"品牌+核心词"，移动端截断也能看到。
- **词块空格分隔**，不连写，提升切词命中率。
- **避免堆砌**：同一词不重复 > 2 次；不强行塞满 45 字符。
- **覆盖搜索意图**：一个标题尽量覆盖"品牌词 + 品类词 + 成分词 + 场景词"四类，至少命中 3 个真实搜索词块。
- **不蹭病种类词**：绝不写"湿疹/皮炎/脚气"等做搜索截流（红线）。

---

## 五、字符数控制

- 京东主标题建议 **≤ 45 字符（约 30 汉字）**；品牌+规格必备，余量留给合规功效/场景词。
- 空格/标点用于分词，不计入汉字数但计入字符视觉长度，留给核心词的空间要算上。
- 生成后**必须**用 `scripts/check_title.py`（默认上限 45）校验字符数与禁用词。

## 六、标题 A/B 测试（用推广验证搜索权重）

1. 准备 2–3 个候选标题（见 `assets/title_template.md` 与 `examples/title_samples.md`）。
2. 用京东快车"品类词计划"分别挂不同标题的创意，跑 7 天。
3. 对比**展现量、点击率（CTR）、加购率**，CTR 高且加购稳的标题定为长期标题。
4. 切换标题时保留历史数据，便于复盘哪类词块更吸睛。

## 七、标题质量自检清单

- [ ] 含品牌词「周郎中」且前置
- [ ] 含关键规格（如 30g）
- [ ] 含核心品类词
- [ ] 无 compliance 文件中的禁用词（脚本零命中）
- [ ] 字符数 ≤ 45 字符
- [ ] 覆盖 ≥ 3 个真实搜索词块（品牌/品类/成分/场景）
- [ ] 无绝对化/疗效承诺用语
- [ ] 已用 `scripts/check_title.py` 跑过，退出码 0

## 八、生成流程（skill 执行顺序）

1. 读 `products.md` 确定 SKU 卖点与定价。
2. 用本文件"三、词库"挑词，套 `assets/title_template.md` 结构。
3. 用 `scripts/check_title.py` 校验 → 修复命中。
4. 输出 2–3 个候选标题 + 各自埋词说明（覆盖哪些搜索词），供用户选择。
5. 需要可直接复制成品时，见 `examples/title_samples.md`。
