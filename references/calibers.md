## 一、供应商双口径（投产比 · 最高优先级）

前提：我方是京东自营**供应商**，按供货结算；使用下列折算前须核实归因成交范围仅为我方商品，且与费用期间、渠道一致。间接占比小不能证明该前提。

```
后台投产比（前台口径，虚高） = 我方商品前台销售额 ÷ 广告花费
真实投产比（供应商口径）     = 后台投产比 × 供货价率
保本前台投产比               = 1 ÷ (供货价率 × 毛利率)     （正贡献、稳定结构的情景线）
目标前台投产比               = 保本前台投产比 × 1.2
```

- 店铺口径 `保本投产比 = 1 ÷ 毛利率` 只是**参考上限**，直接当生死线会每单都亏
  （例：毛利率 50% 时店铺口径 2.0，而供货价率 65% 时对应情景线 3.08；2.0 是较低参考值，不是数学上限）。
- 缺供货价率 / 毛利率 → 保本线只给**区间**并列入数据缺口，**不得拍定值**。
- 此处真实投产比（供应商口径）仅指供货收入/广告费，不是实际利润；毛利率须明确为扣除相应可变费用后的广告前贡献率。速查表仅是假设参考。目标乘1.2是可选情景，不是全账户默认值。

### 保本前台投产比速查表（值 = 1 ÷ (供货价率 × 毛利率)）

## 二、ROAS 恒等式

```
ROAS = CVR × 客单价 ÷ CPC            （CPC 计费）
ROAS = CTR × CVR × AOV ÷ (CPM÷1000)  （CPM 计费）
```

- **CPC 计费不得多乘 CTR**：CTR 只决定流量规模（展现→点击），不进 CPC 的投产恒等式。
- 式中客单价应准确称平均每转化金额，转化事件须与CVR分子相同。成交额/订单行数称平均订单行金额，不是整单客单价或平均件价；订单行不直接等同实际件数。
- 实测校准：27.25 × 13.40% ÷ 2.31 = 1.58（10-13 账户级）。

## 三、保本 CPC 上限

```
令  客单价 × CVR ÷ CPC ≥ 保本前台投产比
→   保本 CPC 上限 = 客单价 × CVR ÷ 保本前台投产比
```
仅在贡献和事件口径已核实且转化假设成立时适用。历史数据推算是情景预期，不是未来投产上限；毛保等非线性费用应单独核算。

### 投放样本与目标贡献的情景补充

以下仅为统计/经营假设，不是平台规则：

```text
固定独立点击、可比CVR为p时，n次成熟点击零成交概率 = (1-p)^n
零成交且单侧置信水平1-alpha时，CVR参考上界 = 1-alpha^(1/n)
希望每转化保留贡献T时，可用广告额 = 每转化广告前贡献M - T
目标CPC情景 = CVR × (M - T)
目标前台ROAS情景 = 每转化前台金额 / (M - T)
```

n必须为正整数，p和alpha在0到1之间；真实点击可能相关、流量异质且存在多重比较，上界不是因果证据或自动关停条件。n须预先定义，不能反复窥视并当固定置信保证。M-T须为正；费用非线性或成交结构变化时重算贡献情景，不直接套固定比例。

## 四、多件装让利


```
最大供货让利率 = 1 − (1 − 当前贡献率) / (1 − 目标贡献率)
最低供货价 = 固定单位可变成本 / (1 − 目标贡献率)
```
- 仅当单位可变成本固定、目标贡献率小于1且口径一致时可用；例如当前50%、目标20%，可让37.5%，不是30%。若费用随价格或活动变化则重算；前台促销如何影响我方供货结算须另行确认，不能直接套供货折扣。

## 五、补货公式

```
日均销 = 近 7 日出库 ÷ 7（按 SKU × 仓 单独算）

基础版   补货量 = max(0, ceil(日均销 × 覆盖天数 − 可用 − 在途))
进阶版   补货量 = max(0, ceil(日均销 × (L + 覆盖天数) + 安全库存 − 可用 − 在途))
         安全库存 = 日均销 × 波动天数（无波动数据取 3–7 天）

B 仓     目标库存 = Σ_i[日均_i × (L_B + L_BC + 覆盖天数_i)] + B仓安全库存
         B 仓补货量 = max(0, 目标库存 − B仓可用 − 在途(供应商→B))
         B 仓安全库存 = 全网日均 × 5–7 天
         B 仓模式下 C 仓补货量 = max(0, ceil(日均_C × (L_BC + 覆盖天数)
                                 + 安全库存_C − 可用_C − 在途_B→C))
           ——C 仓的提前期是 **L_BC**（B→C 在途），不是 L_B；C 仓的货由 B 仓拨给

B 仓预警判据（2026-10-16 修正，原用固定 30 天会必然误报）：
  B 仓压货 = B仓可用 > 全网日均 × (L_B + L_BC + C仓覆盖 + 安全库存)
  B 仓断供 = B仓可用 < 全网日均 × (L_B + L_BC + 3)
  B 仓可拨保留量 = 全网日均 × (L_B + L_BC + 3)，拨出量补回 B 仓采购量

大促     补货量 = max(0, ceil(日均销 × 大促系数 × (L + 覆盖天数) − 可用 − 在途))
         大促系数 2.5–3；覆盖天数 ×2–2.5
```

覆盖天数分层：A 爆款 18–22 天 / B 常规 22–26 天 / C 慢销 25–30 天。

## 六、偏仓与调拨

```
偏仓系数 = 该仓库存占比 ÷ 该仓销量占比   （>1.5 积压 / <0.67 缺货）
可调出量 = max(0, 供体仓可用 − 供体仓目标库存)
调拨量   = min(可调出量, 受体仓补货量)，同大区优先
受体仓最终补货量 = 原补货量 − 调入量（调入部分不再下采购单）
```

## 八、综合毛保与广告抵扣的贡献情景

只适用于合同明确按同范围净前台销售保障综合毛利、合资格广告抵补差且无跨期结转的情景。合同已有综合毛利须单独核实，不能用全部采购入库额代替已售成本。字段解释和工具见 `contribution_tool.md`。

```text
毛保缺口 = max(0, 净前台销售额 × 毛保比例 − 已有综合毛利)
实际广告抵扣 = min(毛保缺口, 合资格广告费用 × 抵扣比例)
实际补差 = 毛保缺口 − 实际广告抵扣
广告前贡献 = 对应供货收入 − 产品/包装/物流/税/其他可变费用 − 实际补差
广告后贡献 = 广告前贡献 − 全额广告费
```

没有缺口时抵扣为零，不能产生额外收益。比例和税额均显式输入，不把某账户合同预设成所有用户的规则。包装、运费等是否已含在成本、净收入或扣款中需先核重；结果不是净利润，也不是广告因果收益。
