## 一、供应商双口径（投产比 · 最高优先级）

前提：我方是京东自营**供应商**，按**供货价**结算；京准通成交金额是**订单行口径**（我方 SKU 前台销售额）。

```
后台投产比（前台口径，虚高） = 我方商品前台销售额 ÷ 广告花费
真实投产比（供应商口径）     = 后台投产比 × 供货价率
保本前台投产比               = 1 ÷ (供货价率 × 毛利率)     ← 生死线，低于即每单亏
目标前台投产比               = 保本前台投产比 × 1.2
```

- 店铺口径 `保本投产比 = 1 ÷ 毛利率` 只是**参考上限**，直接当生死线会每单都亏
  （例：毛利率 50% 时店铺口径 2.0，而供货价率 65% 时真实生死线 3.08）。
- 缺供货价率 / 毛利率 → 保本线只给**区间**并列入数据缺口，**不得拍定值**。

### 保本前台投产比速查表（值 = 1 ÷ (供货价率 × 毛利率)）

## 二、ROAS 恒等式

```
ROAS = CVR × 客单价 ÷ CPC            （CPC 计费）
ROAS = CTR × CVR × AOV ÷ (CPM÷1000)  （CPM 计费）
```

- **CPC 计费不得多乘 CTR**：CTR 只决定流量规模（展现→点击），不进 CPC 的投产恒等式。
- 客单价 = 我方 SKU 订单行金额 ÷ 订单行数（订单行口径，非整单）。
- 实测校准：27.25 × 13.40% ÷ 2.31 = 1.58（10-13 账户级）。

## 三、保本 CPC 上限

```
令  客单价 × CVR ÷ CPC ≥ 保本前台投产比
→   保本 CPC 上限 = 客单价 × CVR ÷ 保本前台投产比
```
CPC 高于此值 → 必亏。

## 四、多件装让利

```
最大让利率 = 毛利率 − 保底毛利率
多件装售价 ≥ 单支价 × 件数 × (1 − 最大让利率)
```
- 让利的是**前台价**，亏的是**供货价结算后的毛利**；缺供货价率或毛利率时，让利幅度只能标「待定」。

## 五、补货公式

```
日均销 = 近 7 日出库 ÷ 7（按 SKU × 仓 单独算）

基础版   补货量 = max(0, ceil(日均销 × 覆盖天数 − 可用 − 在途))
进阶版   补货量 = max(0, ceil(日均销 × (L + 覆盖天数) + 安全库存 − 可用 − 在途))
         安全库存 = 日均销 × 波动天数（无波动数据取 3–7 天）

B 仓     目标库存 = Σ_i[日均_i × (L_B + L_BC + 覆盖天数_i)] + B仓安全库存
         B 仓补货量 = max(0, 目标库存 − B仓可用 − 在途(供应商→B))
         B 仓安全库存 = 全网日均 × 5–7 天

大促     补货量 = max(0, ceil(日均销 × 大促系数 × (L + 覆盖天数) − 可用 − 在途))
         大促系数 2.5–3；覆盖天数 ×2–2.5
```

覆盖天数分层：A 爆款 18–22 天 / B 常规 22–26 天 / C 慢销 25–30 天。

## 六、偏仓与调拨

```
偏仓系数 = 该仓库存占比 ÷ 该仓销量占比   （>1.5 积压 / <0.67 缺货）
可调出量 = max(0, 供体仓可用 − 供体仓目标库存)
调拨量   = min(可调出量, 受体仓补货量)，同大区优先
受体仓最终补货量 = 原补货量 − 调入量（调入部分不再下采购单）
```
