## 一、评价回复话术（按场景细分）

### 1.1 通用好评
> 感谢您选择周郎中草本外用抑菌护理系列，您的认可是对我们最大的鼓励～周郎中坚持植物配方、温和不刺激，希望能一直陪伴您的家庭护理。有任何使用疑问随时联系在线客服哦～

### 1.2 中评（体验一般）
> 谢谢您的真实反馈～周郎中是外用抑菌护理产品，每个人肤感不同。若觉得使用感或气味有差别，欢迎联系客服，我们帮您看看是否适合您的使用场景，也持续优化产品体验。

### 1.3 差评（功效未达预期）
> 非常抱歉这次体验没达到您的预期。周郎中为外用抑菌护理产品，不做治疗用途，每个人肤感与需求不同。如有任何不适或疑问请直接联系店铺客服，我们会第一时间为您处理，也欢迎告知具体情况帮您判断是否适合您的使用场景。

### 1.4 物流/发货问题
> 抱歉让您久等了！物流时效受天气与区域影响偶有波动，我们已同步仓库优先跟进您的订单。如有紧急需求请直接联系客服，我们帮您催件或协调处理。

### 1.5 包装破损
> 很抱歉包装在运输中受损影响体验。我们已登记，会为您补发完好包装或协调售后；同时已反馈仓库加强打包防护。麻烦您联系客服提供照片，我们尽快处理。

### 1.6 疑似假货/正品质疑
> 周郎中为京东自营/官方旗舰在售，每支均有消字号资质与防伪可查。如您对商品有任何疑问，欢迎联系客服核对批号，我们提供正品保障与售后跟进。

### 1.7 未收到/少件
> 抱歉给您添麻烦！请先查看是否家人代收或放快递柜；如确认少件，联系客服提供订单号，我们核实后为您补发或处理，确保您收到完整订单。

### 1.8 用法疑问
> 本品为外用护理，取适量涂抹于所需部位即可，具体以产品说明为准。若使用中想了解更细的用法或搭配，随时找客服，我们详细为您说明。

**话术红线**：不承诺疗效、不贬竞品、不绝对化、不引导改评返现（只给解决方案）。

## 三、大促作战计划（618 / 双11，适配周郎中自营）

> 大促筹备提前 45–60 天启动。以下为 T-60→T+7 作战节奏，按周郎中自营（京准通 + 12 仓）适配。

### T-60 天：战略筹备
- [ ] 定 GMV 目标，倒推流量/转化需求
- [ ] 与采销对齐会场坑位/资源位（自营走京准通）
- [ ] 规划货品组合：引流款（30g 抑菌膏低价）、利润款、活动款
- [ ] 单 SKU 毛利测算（含平台扣点+广告+物流），设活动价架构
- [ ] 触发 12 仓补货：`补货量=(近7日出库÷7×20)-可用库存-采购未到货`，向上取整 ≥0

### T-30 天：准备期
- [ ] 定稿创意素材：主图、详情页、短视频（对标竞品水准）
- [ ] 配置大促机制：预售、定金膨胀、跨店满减、优惠券
- [ ] 搭建推广：快车关键词、京速推场景、海投 ROI 目标
- [ ] 直播/内容排期；CRM 触达既有客户（会员权益、优先购）
- [ ] 客服扩容 + FAQ 话术预置（含消字号合规问答）

### T-7 天：蓄水期（预热）
- [ ] 激活预售/定金收集
- [ ] 渐进加投广告蓄力
- [ ] 社媒剧透（小红书/抖音/微博）
- [ ] 监控竞品定价，必要时调位

### T 日：爆发期
- [ ] 作战室：实时 GMV 看板 + 库存监控 + 客服队列
- [ ] 按实时数据逐时调广告出价
- [ ] 监控库存，触发补货预警
- [ ] 整点闪购（10/14/20/0 点）

### T+1~T+7：复盘期
- [ ] 产出大促复盘报告（对标目标）
- [ ] 拆解流量来源/转化漏斗/分渠道 ROI
- [ ] 处理退货与售后高峰
- [ ] 留存动作：感谢信、评价邀约、会员入会
- [ ] 团队复盘 + 经验归档

## 五、数据复盘框架（含公式）

### 5.1 核心指标公式
```
CTR  = 点击量 ÷ 展现量
CVR  = 下单量 ÷ 点击量
UV价值 = 成交金额 ÷ 访客数
ROI  = 成交金额(归因) ÷ 推广花费
加购率 = 加购数 ÷ 访客数
可售天数 = 可用库存 ÷ 近7日日均出库
```

### 5.2 周报模板
| 维度 | 本周值 | 环比 | 结论 | 下期动作 |
|---|---|---|---|---|
| 展现/点击/CTR | | | | |
| 加购率/CVR | | | | |
| 花费/ROI | | | | |
| 好评率/差评TOP | | | | |
| 可售天数 | | | | |

输出：本期结论 + 下期 3 条可执行动作（如"快车品类词提价 10%""主图加容量对比""差评话术补充 XX 场景"）。

### 5.3 月报/大促报
在周报基础上加：分渠道 ROI 拆解、货品结构（引流/利润款占比）、库存健康度、活动 ROI 归因。
