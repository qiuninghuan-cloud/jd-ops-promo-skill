# 评价 / 活动 / 数据复盘模块 · 详版

本文件指导 Skill 生成评价回复、问大家、活动准备和经营复盘。示例必须结合当前 SKU 说明书、店铺类型、后台权限和平台规则复核；自营/POP、仓网、活动入口和可用字段不预设。

> 话术以真实商品事实和平台规则为准。用户指定保留词按 SKILL.md 处理；不承诺未核实效果，不以返现、赠品、删改评价换取好评。

## 一、评价回复话术（按场景细分）

### 1.1 通用好评
> 感谢您的反馈与支持！商品成分、使用方式和注意事项请以当前包装及说明书为准。如有订单或使用疑问，欢迎通过订单页面联系客服。

### 1.2 中评（体验一般）
> 谢谢您的真实反馈～周郎中是外用抑菌护理产品，每个人肤感不同。若觉得使用感或气味有差别，欢迎联系客服，我们帮您看看是否适合您的使用场景，也持续优化产品体验。

### 1.3 差评（功效未达预期）
> 非常抱歉这次体验没达到您的预期。周郎中为外用抑菌护理产品，不做治疗用途，每个人肤感与需求不同。如有任何不适或疑问请直接联系店铺客服，我们会第一时间为您处理，也欢迎告知具体情况帮您判断是否适合您的使用场景。

### 1.4 物流/发货问题
> 抱歉给您带来等待。请通过订单页面联系客服提供订单信息，我们会按当前物流和售后流程核实处理。

### 1.5 包装破损
> 很抱歉包装受损影响体验。请通过订单页面联系客服并提供必要凭证，我们会按售后流程核实处理。

### 1.6 疑似假货/正品质疑
> 商品渠道、资质、防伪方式和售后政策请以当前商品页面、包装标识和订单客服流程为准。如有疑问欢迎联系客服核实批次和订单。

### 1.7 未收到/少件
> 抱歉给您添麻烦！请先查看是否家人代收或放快递柜；如确认少件，联系客服提供订单号，我们核实后为您补发或处理，确保您收到完整订单。

### 1.8 用法疑问
> 本品为外用护理，取适量涂抹于所需部位即可，具体以产品说明为准。若使用中想了解更细的用法或搭配，随时找客服，我们详细为您说明。

**回复标准**：先确认事实和订单，再承认体验、给处理入口、说明适用边界；不争辩、不承诺未核实补发/退款/资质/效果，不引导删除或修改评价。

## 二、问答 / 问大家话术（扩量）

| 用户常问 | 合规回答要点 |
|---|---|
| 这个能治湿疹/皮炎吗 | 本品为消字号外用抑菌护理产品，不做治疗用途；如有皮肤问题建议咨询专业人士 |
| 孕妇/小孩能用吗 | 外用护理产品，适用性请依照该商品说明书，并咨询专业人士 |
| 和竞品比哪个好 | 请按当前页面可核实的规格、成分、到手条件和自身需求比较，客服可协助核对信息 |
| 怎么用 | 外用，取适量涂抹于所需部位，具体以产品说明为准 |
| 味道大吗 | 草本淡香、气味清淡，不刺鼻 |
| 油腻吗 | 易吸收、不黏腻（油类亦强调"不黏腻"） |
| 能带上飞机/随身吗 | 30g 小支居家外出、随身便携很方便 |
| 一支能用多久 | 30g 大容量，日常护理可用较久，具体看使用频率 |
| 口腔抑菌液能吞吗 | 外用护理液，请勿吞咽，使用方式请严格依照本品说明书 |
| 保质期多久 | 以产品包装标注为准，未开封请置于阴凉干燥处 |

## 三、大促作战计划（618 / 双11，适配周郎中自营）

> 大促按后台报名周期和店铺实际权限倒排；以下阶段是检查清单，不是固定天数或必有资源。

### T-60 天：战略筹备
- [ ] 定 GMV 目标，倒推流量/转化需求
- [ ] 与采销对齐会场坑位/资源位（自营走京准通）
- [ ] 规划货品组合：引流款（30g 抑菌膏低价）、利润款、活动款
- [ ] 单 SKU 广告前贡献与广告后收益测算（成本不可重复扣减），设活动价架构
- [ ] 按后台可用库存、锁定库存、在途、区域库存和供应周期测算覆盖天数；补货/调拨量先形成预警，按实际供应链流程确认

### T-30 天：准备期
- [ ] 定稿创意素材：主图、详情页、短视频（对标竞品水准）
- [ ] 配置大促机制：预售、定金膨胀、跨店满减、优惠券
- [ ] 搭建推广：快车关键词、京速推场景、海投 ROI 目标
- [ ] 直播/内容排期；CRM 触达既有客户（会员权益、优先购）
- [ ] 客服扩容 + FAQ 话术预置（含消字号合规问答）

### T-7 天：蓄水期（预热）
- [ ] 激活预售/定金收集
- [ ] 渐进加投广告蓄力
- [ ] 社媒剧透（小红书/抖音/微博）
- [ ] 记录可验证的竞品价格、规格、到手条件和采集时间；任何调价/调位先核算贡献和授权

### T 日：爆发期
- [ ] 作战室：实时 GMV 看板 + 库存监控 + 客服队列
- [ ] 按实时数据逐时调广告出价
- [ ] 监控库存，触发补货预警
- [ ] 核实活动页面的场次、资源位和时间；仅在已报名且后台可执行时安排

### T+1~T+7：复盘期
- [ ] 产出大促复盘报告（对标目标）
- [ ] 拆解流量来源/转化漏斗/分渠道 ROI
- [ ] 处理退货与售后高峰
- [ ] 留存动作：感谢信、评价邀约、会员入会
- [ ] 团队复盘 + 经验归档

## 五、数据复盘框架（含公式）

### 5.1 核心指标公式
```
CTR  = 点击量 ÷ 展现量
CVR  = 下单量 ÷ 点击量
UV价值 = 成交金额 ÷ 访客数
ROI  = 成交金额(归因) ÷ 推广花费
加购率 = 加购数 ÷ 访客数
可售天数 = 可用库存 ÷ 选定窗口日均出库；窗口、区域和库存口径必须写明
```

### 5.2 周报模板
| 维度 | 本周值 | 环比 | 结论 | 下期动作 |
|---|---|---|---|---|
| 展现/点击/CTR | | | | |
| 加购率/CVR | | | | |
| 花费/ROI | | | | |
| 好评率/差评TOP | | | | |
| 可售天数 | | | | |

输出：本期结论 + 下期 3 条可执行动作（如"快车品类词提价 10%""主图加容量对比""差评话术补充 XX 场景"）。

### 5.3 月报/大促报
在周报基础上加：分渠道 ROI 拆解、货品结构（引流/利润款占比）、库存健康度、活动 ROI 归因。
