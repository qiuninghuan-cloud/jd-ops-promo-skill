# 证据账本 · 质量门 · 置信度规则

> 借鉴开源电商 skill 的 Evidence Ledger / Pass-Fail 质量门做法，按消字号场景裁剪。
> 用途：产出前先分级，产出后过门；诊断类结论标置信度与数据缺口。

---

## 一、证据账本：每条卖点必须定级

| 标记 | 定义 | 可写？ | 示例 |
|---|---|---|---|
| ✅ 已确认 | 有逐 SKU 可追溯材料或用户明确确认，记录来源与日期 | 通过合规核对后可写 | 包装确认规格「30g」 |
| 📄 有依据 | 有外部可查来源（说明书、已上架详情页、包装） | 可写并注明来源 | 「外用抑菌」（依据：产品备案/说明书） |
| ⚠️ 待补证 | 想写但缺来源 | **先问用户** | 「抑菌率 99%」「销量领先」「复购率高」 |
| 🚫 禁止 | 疗效/病种/绝对化/需资质 | 改写或删除 | 「治疗湿疹」「三天见效」「第一品牌」 |

### 消字号专用判定

| 想表达的内容 | 等级 | 合规改写 |
|---|---|---|
| 抑菌率 99% / 杀菌率 | 🚫（除非有检测报告） | 「外用抑菌」 |
| 临床验证 / 医学证明 | 🚫 | 「草本植物配方」 |
| 治愈案例 / 用户康复 | 🚫 | 「日常护理」 |
| 湿疹 / 皮炎 / 脚气 / 痤疮 | 🚫（病种词） | 「肌肤不适的日常护理」 |
| 修复受损肌肤 / 舒缓 | 🚫 | 「温和护理」 |
| 儿童可用 | ⚠️（需看备案适用范围） | 按备案写「成人适用」或「儿童请在成人指导下使用」 |

## 二、质量门（Pass/Fail，硬性阻断）

不做「80/100」式伪精确评分，按维度做通过/失败判定。命中任一阻断项 → 不可交付，改到通过为止。

### 门 1：标题
| 检查项 | 阻断条件 | 工具 |
|---|---|---|
| 禁用词 | 命中任一合规清单词 | `check_title.py` |
| 暗示疗效 | 命中正则（3天见效/一抹就好/告别XX 等） | `check_title.py` |
| 字符数 | > 45 字符 | `check_title.py` |
| 品牌词 | 缺「周郎中」或未前置 | `check_title.py` |
| 规格 | 主推规格未写（如 20g/30g/300ml） | 人工 |
| 搜索覆盖 | 命中 < 3 个真实搜索词块 | 人工 |

### 门 2：主图文案
- 含禁用词 / 疗效承诺 / 绝对化 / 贬竞品 → 阻断
- 卖点未标证据等级 → 阻断
- KV 角色混乱（五张全是卖点堆砌，无 Hero/Proof 区分）→ 阻断

### 门 3：详情页
- 出现病种名（湿疹/皮炎/脚气/痤疮/痔疮）→ 阻断
- 承诺治愈、承诺无效退款 → 阻断
- 编造批准文号、检测编号、销量、评价数 → 阻断
- 用法说明缺失（用量、频次、注意事项）→ 阻断

### 门 4：投放方案
| 检查项 | 阻断条件 |
|---|---|
| 保本 ROI | 未按 `decision_rules.md` 算 1÷(供货价率×广告前贡献率)，或未说明缺失参数 |
| 止损线 | 未写"多少天 ROI 低于多少就停/降" |
| CPC 匹配 | 未核对事件与金额，或将情景预期当作理论上限 |
| 口径 | 自营未区分前台 GMV 与供货价结算 |
| 分时/地域 | 完全未提 |

### 门 5：诊断结论
| 检查项 | 阻断条件 |
|---|---|
| 数据口径 | 未说明是前台 GMV 还是供货价口径 |
| 置信度 | 结论未标高/中/低 |
| 数据缺口 | 未列出"还需要什么报表才能精修" |
| 动作可执行性 | 只给方向没给具体数值/天数 |

## 三、置信度标注规则（诊断类输出）

| 置信度 | 判定标准 | 示例 |
|---|---|---|
| **高** | 有后台真实数据直接算出（比值、环比） | 「客单价 27.25，环比 -15.6%」（来自 31,390÷1,152） |
| **中** | 由行业经验 + 部分数据推断 | 「加购未支付人群流失在价格环节」 |
| **低** | 缺数据、靠类比或猜测 | 「主力计划投的是低价品」（未导出商品维度报表，待确认） |

> 输出格式：`结论（置信度：中）｜依据：xxx｜待确认：xxx`

## 四、数据缺口清单（诊断必附）

当前账户诊断常见缺口，逐条列出向用户索取：

| 缺什么 | 影响什么 | 向谁要 |
|---|---|---|
| SKU 供货价 / 毛利率 / 扣点 | 保本 ROI、让利空间 | 用户（内部） |
| 关键词报表（词/展现/点击/花费/订单/ROI） | 否词、长尾加投词 | 京准通导出 |
| 分时报表 | 砍低效时段 | 京准通导出 |
| 商品维度销售报表 | 定位拉低客单价的 SKU | 商智/京麦 |
| 搜索词报告 | 挖高转化长尾词 | 京准通 |
| 竞品到手价 | 价格竞争力判断 | 前台人工核对 |
