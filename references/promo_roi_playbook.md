# 提高投产比（ROAS）实操手册 · 周郎中专属

> 本文件是推广模块的"提高投产"深度方法论，配套 `promo.md` 使用。核心结论：**投产不是靠加预算，靠"精准流量 + 高转化 + 控 CPC"**。

---

## 一、先算盈亏线（所有动作的起点）

> **口径前提（供应商，2026-10-15 统一）**：京准通成交金额是**订单行口径**（我方 SKU 前台销售额），
> 我方按供货价结算。保本线必须用供应商口径，**不能直接套"1÷毛利率"的店铺公式**。

> **公式以 `references/calibers.md` 为准（口径唯一来源），本文不重复定义。**
> 后台投产比（前台口径，虚高）→ 真实投产比（乘供货价率）→ **保本前台投产比**（供应商生死线）→ 目标投产比（× 1.2）。

- 缺供货价率/毛利率 → 保本线给**区间**并列入数据缺口，不许拍一个数当结论。
- 店铺口径 1÷毛利率 只作参考上限；真实生死线是含供货价率的**保本前台投产比**，两者差距可达 50% 以上。
- 设置投产比目标后，**观察 3–7 天再微调**，频繁改会重置系统学习、流量波动。
- 分场景：新品测款期降低目标 ROI 拿流量；爆款成熟期拉高 ROI 严控花费；活动期小幅下调。

---

## 二、ROAS 恒等式与四杠杆（提投产就从这四项下手）

> **ROAS 恒等式见 `references/calibers.md`**：`ROAS = CVR × 客单价 ÷ CPC`（CPC 计费）。
> CPC 计费下 CTR 只决定流量规模，**不得多乘 CTR**；CPM 计费才用 `CTR × CVR × AOV ÷ (CPM÷1000)`。

| 杠杆 | 提产动作 | 对应模块 |
|---|---|---|
| CTR↑ | 换高点击主图/创意、程序化创意测图、标题含核心词 | 主图/详情页、快车创意 |
| CVR↑ | 详情页痛点+卖点、价格优势、优惠券/满减、好评管理、问大家 | 详情页、评价模块 |
| AOV↑ | 膏+油组合装、满减、赠品、套装 | 促销机制 |
| CPC↓ | 长尾精准词、否词、DMP 精准人群、分时低效段暂停 | 快车/海投/触点 |

> ⚠️ **只看 ROI 不看客单价是误区**：低客单高 ROI 未必盈利，高客单适中 ROI 反而利润更高。周郎中可推"膏+油组合装"拉 AOV。

## 三、快车 3 层关键词矩阵（订单多 3–5 倍）
- 核心词 20% / 长尾词 50% / 竞品词 30%。
- 长尾词 CPC 仅大词 1/3，转化率却 3 倍——**投产主力在长尾**。
- 用"关键词推荐"工具挖高转化长尾；核心词短语、长尾精确；每周加否词。

---

## 四、DMP 四层人群漏斗（CPC 可降 40%、转化翻倍）
- 高潜（类目浏览/加购未购，溢价 30–50%）→ 竞品人群（拦截）→ 复购唤醒（老客 180 天未回购，京挑客召回）→ 排除（已购本品）。
- 行为标签圈人法：品牌 7 天浏览 / 30 天搜索 / 120 天加购 / 180 天购买；类目 3 天浏览 / 60 天购买。类目购买与品牌加购 ROI 通常最高。

---

## 五、智能出价 / 投产比控制的坑（必读）
- 开"促进成交 + 投产比控制"后：**人群溢价失效、分时折扣系数失效**（仅"不投放"开关生效）。
- 想要人群分层提投产 → 用"控点击成本 + 智能调价"，手动管溢价与分时。
- 想要系统稳 ROI → 用"投产比控制"，别再调人群/分时（调了也白调）。
- 新建单元参考系统建议出价；不建议频繁改出价方式与出价。

---

## 六、否词：每周从搜索词报告挖
- 导出近 7 天搜索词 → 筛"点击多、无转化、不相关" → 加否词。
- 固定否词库：泛意图（图片/壁纸/教程）、口服食品、病种治疗词、儿童药、低价欺诈（9.9/免费领）。
- 海投/京速推同理：低质词每周清理，否则预算被泛词吃。

## 七、时段与地域
- 黄金 3 段（早 7–9 / 午 12–14 / 晚 19–22）系数 1.2–1.5；凌晨 1–6 系数 0.3 或暂停；大促前 3 天核心时段 2.0。
- 地域：关长期无转化地区；北方/特定需求品重点投对应省份（周郎中消字号偏全国，可先全量再剔除低效省）。

|---|---|---|---|---|---|---|
| （填） | | | | | | 提价/降出价/否词/关停/放量 |

## 九、执行闭环：每条动作必须带五要素（2026-10-15 补）

任何投放动作（暂停/改价/加预算/否词/换创意/上下架）写进方案前，必须补齐：

| 要素 | 写什么 | 反例（不合格） |
|---|---|---|
| **责任人** | 谁执行（用户本人/采销/设计）——skill 只出稿，不代操作 | "建议优化主图"——没人执行 |
| **损失上限** | 最多亏多少/烧多少花费就停（金额或天数） | "先跑跑看"——无上限 |
| **观察期** | 改动后几天内不看数据、多久后判优劣 | 当天改当天看 |
| **复核时间** | 具体哪天/周几复盘，对照什么指标 | "下周再看看" |
| **回退条件** | 出现什么信号就改回原设置（如 CPC>X、ROI<Y、展现量跌 Z%） | 只进不退 |

示例：暂停苗草癣全站智能（责任人：用户，今晚执行；损失上限：暂停即止血，无新增花费；
观察期：停后 3 天不动其他计划；复核时间：下周一对照计划报表；
回退条件：该品在售池内且手动计划 3 天后起量 <50% → 恢复半预算重测）。

## 十、避坑清单
1. 追求高投产致流量枯竭 → 盈利前提下适度放量。
2. 不算保本盲目设目标 → 先算毛利率。
3. 频繁改计划（<3–7 天） → 系统学习期，小幅微调。
4. 只看 ROI 不看客单价 → 结合 AOV 看利润。
5. 新品一上来开智能 → 先手动精确词养样本。
6. 单计划猛加预算 → 用多计划复制放量。
7. 海投同时开自动拓量+全量人群 → 泛词吃预算。

## 十一、周郎中落地建议（首月）
1. 先算紫草膏/润肤油/口腔液三 SKU 的**供货价率 + 毛利率**（供应商口径）→ 定各品保本前台投产比与目标投产比；拿不到就列数据缺口。
2. 快车建 3 层矩阵（核心/长尾/竞品），长尾占 50% 预算。
3. 海投日 200–300 托管 ROI 2.5–3，每周否词。
4. 京速推测品，跑出高转化 SKU 加投。
5. DMP 建"高潜+复购唤醒+排除"人群包。
6. 每周填诊断表，关停 ROI<保本 计划，预算倾斜高 ROI。
7. 详情页/评价同步优化（提 CVR、AOV），这是投产的"后半程"。
