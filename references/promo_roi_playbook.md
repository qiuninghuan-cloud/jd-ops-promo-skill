# 投产、客单价与成本判断

## 字段和公式

同一日期、归因、订单定义与币种下：

- CTR = 点击数 / 展现数。
- CPC = 广告花费 / 点击数；CPM = 广告花费 / 展现数 × 1000。
- CVR = 归因订单数 / 点击数；AOV = 归因成交金额 / 同一定义的归因订单数。
- CPA = 广告花费 / 归因订单数。
- ROAS = 归因成交金额 / 广告花费 = CVR × AOV / CPC。CPC 计费下这个分解不再乘 CTR。
- 若以 CPM 表达：ROAS = 1000 × CTR × CVR × AOV / CPM。

百分比计算用小数。分母为0时标记未定义，不填0或无穷大当作业务结论。后台若以订单行数计算 CVR，则 AOV 分母也用订单行数并标为“每订单行金额”，不能叫消费者客单价。跨 SKU 平均值用汇总金额/汇总订单计算，不平均各行比率。后台标为 ROI 的收入/花费指标保留原名，解释为 ROAS，不混同利润投资回报率。

CTR 影响流量规模、质量和竞价结果，但 CTR 上升不必然带来 ROAS 上升。诊断先查流量组合，再看 CPC、CVR 与成交均价。

## 盈利线

先确定收入属于商家实收、消费者成交额还是自营供货结算。自营不能把前台零售价当作供应商收入。

广告前贡献 C = 预计可结算净收入 − 商品成本 − 履约成本 − 平台费用 − 商家承担且尚未扣除的优惠 − 预计退货/售后损耗。

以同一批成交的报表收入 R 为分母，定义贡献率 m=C/R；当 m>0，且广告归因口径与该批收入和成本可匹配时，测算保本 ROAS=1/m。m≤0 时广告无法仅靠提高 ROAS 修复商品本身的负贡献。各项不得重复扣减，退款按净收入口径处理后只再计额外损耗。

仅知道采购毛利率时，不能直接给出确定保本线；列明缺失成本或给出注明假设的区间。该模型未证明增量，也不涵盖未计入的固定费用。目标 ROAS 需结合利润要求和获量能力，不固定乘1.2。

## 客单价如何影响推广

CVR 和 CPC 不变时，提高 AOV 会提高 ROAS；实际提价/套装可能降低 CVR，优惠和退货也会侵蚀贡献。比较单品与高客单 SKU 的真实成交均价、每单贡献、广告 CVR 和 CPA，不能按标价排序决定主推。

算例（纯演示）：CVR=10%、AOV=40元、CPC=2元，则 ROAS=2、CPA=20元。若每单广告前贡献仅12元，则按该归因模型每单差额为-8元，较高客单也不代表盈利。

## 判断与动作

- 当日/近日报表归因尚未成熟：用于控消耗和排查异常；不能仅因当天 ROAS 低于历史值就停投。
- 样本少、无订单：核对流量相关性、落地页、价格、库存和跟踪。结合历史 CVR 预期订单及测试成本上限判断，不使用统一点击数或7天无单阈值。
- 成熟样本持续低于测算目标：定位主要消耗来源，提出降价、收窄流量、暂停或调整商品方案；动作取决于贡献、目标和授权，不自动全停。
- 成熟表现稳定且贡献合理：在预算范围内小步测试扩量，看新增消耗对应的边际成交/贡献；平均 ROAS 高不保证新增预算有效。
- 达到已授权的测试损失/支出上限或出现明确异常：按预定止损方案处理，无需为等归因而继续无限消耗。

把观察事实、解释假设、待验证实验分开。金额列核验示例：花费98.99元、成交52.77元、14点击时 CPC约7.07元、ROAS约0.53；旁边的 CPM 不能替代花费。
