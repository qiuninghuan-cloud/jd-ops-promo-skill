# 消字号商品标题/文案合规词规范

本文件定义周郎中品牌消字号（卫生消毒用品）在京东标题、主图、详情页、推广创意中**必须规避**与**可以使用**的词。违反会触发平台审核下架、降权，严重者扣分销店。

> 说明：以下"可用/禁用"清单来自历史运营约定，平台规则与《广告法》会变动，每次大促前务必用 `scripts/check_title.py` 复检，并对照京东"商品发布规范"最新版人工复核一遍。

> **口径统一**：标题内部上限为 45 个 Unicode 字符，含字母、数字、空格和标点，用 `scripts/check_title.py --max 45` 校验；平台实际限制运行时核验。

---

## 一、红线（绝对禁用）

以下词在任何位置（标题、主图文字、详情页、推广创意、问答）都不得出现：

| 类别 | 禁用词示例 |
|---|---|
| 医疗功效宣称 | 治疗、医治、疗效、治愈、根治、疗程、处方、药用、药到病除 |
| 抗炎/杀菌类越界 | 消炎、抗菌、杀菌、灭菌、消毒（注：消字号可"抑菌"，但"抗菌/杀菌/消毒"易被判定为功效越界，谨慎） |
| 症状/病种词 | 湿疹、皮炎、脚气、痤疮、痔疮、口腔溃疡（作为"治疗对象"出现时禁用）、真菌感染 |
| 修护/舒缓越界 | 修护、修复、舒缓、镇定（护肤向功效词，消字号不可用） |
| 预防/承诺类 | 预防、防止、杜绝、100%有效、无效退款、秒杀、神效、专治 |
| 绝对化用语 | 最、第一、国家级、顶级、极致、万能（违反《广告法》绝对化用语条款） |
| 暗示疗效的场景词 | "一抹就好""三天见效""告别XX""XX天见效"等承诺式表达 |

**核心原则**：消字号只能做"抑菌 + 清洁 + 外用护理"层面的描述，**不得暗示或明示治疗任何疾病**。

## 二、可用词（安全表达）

| 用途 | 可用词 |
|---|---|
| 核心功效 | 抑菌、抑制细菌、清爽、洁净、外用 |
| 成分/配方 | 草本、植物配方、紫草、天然、温和、植物萃取 |
| 使用场景 | 日常护理、家庭常备、随身、居家、外出 |
| 人群/部位 | 成人、肌肤、口腔（作为部位名词，不暗示治疗）、手部、足部 |
| 体验描述 | 易吸收、不黏腻、气味清淡、温和不刺激 |

## 三、易混词辨析

- **抑菌 vs 抗菌**：优先用"抑菌"（抑制细菌繁殖），避免"抗菌"（易被理解为杀灭/防护功效）。**聚维酮碘口腔液标题须写"口腔抑菌液"，不写"口腔抗菌液"**。
- **护理 vs 修护**：用"护理/日常护理"，不用"修护/修复"。
- **草本 vs 药用**：用"草本/植物配方"，不写"中药/药用"。
- **口腔 vs 口腔溃疡**：可写"口腔抑菌"，不可写"口腔溃疡/口腔抗菌液治溃疡"。
- **清爽 vs 舒爽**：用"清爽/温和不刺激"，避免"舒缓/镇定"等护肤越界词。
- **大容量 vs 最大**：用"30g 大容量"客观陈述，不用"最大/最多"绝对化。

---

## 四、标题字符数约束

- 主标题内部上限 **≤ 45 字符（含空格/标点）**；核心词前置、不堆砌为准。
- 标题断句用空格分隔词块，便于搜索分词；避免连续重复同一词。
- 品牌词「周郎中」固定置于标题前部或紧邻核心词，强化品牌搜索占位。
