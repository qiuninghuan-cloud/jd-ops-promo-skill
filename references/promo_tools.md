# 京东推广工具体系全览（京东所有推广）

> 适用：周郎中消字号外用抑菌（京东自营供应商身份）。
> 用途：做推广方案时，先按「流量场」选工具组合，再定预算与出价，不要只盯着快车。
> ⚠️ 会变的硬规则（工具下线、改名、门槛、扣点）**运行时核验京准通最新界面**；本文件只写长期稳定的定位与打法逻辑。

---

## 〇、京东推广全景：按「流量场」分层

```
┌─ 搜索场（人找货）── 京东快车·关键词 / 智能推广 / 全店推广 / 全站智能 / 新品 / 新客 / 品牌追击
├─ 推荐场（货找人）── 京东快车·推荐场景 / 购物触点 / 海投 / 京速推
├─ 品牌场（曝光）── 京东展位（CPM）/ 品牌合约（CPT/CPM）/ 品牌聚效 / 品牌广告
├─ 站外场（拉新）── 京东直投（腾讯·巨量·百度·快手）/ 京挑客 CPS / 京东联盟 CPS
├─ 内容场（种草）── 京东直播 / 逛·发现好货 / 短视频 / 京任务内容种草
├─ 活动场（爆发）── 秒杀 / 9.9 特卖 / PLUS 会员日 / 品牌日 / 品类会场 / 京东健康会场
├─ 私域场（复购）── 店铺会员 / 粉丝群 / 京东会员通 / 京麦 CRM / 短信·咚咚触达 / 店铺券·神券
└─ 数据场（底座）── DMP / 京东数坊（4A人群资产）/ 京东商智 / 京准通报表中心
```

**一句话选工具**：
- 要**销量和投产** → 搜索场（快车关键词/智能）
- 要**铺量和动销** → 推荐场（海投/京速推/触点）
- 要**心智和大曝光** → 品牌场（展位/合约）
- 要**站外新客** → 直投/京挑客
- 要**爆发** → 活动场（秒杀/会场，需采销提报）
- 要**复购** → 私域场（会员/CRM/券）

## 一、搜索场：京东快车（投产基本盘）

> 后台实际看到的 campaignType：`2`=关键词推广、`61`=智能化、`3`=全店商品推广、`153`=全站智能推广(shopSmart)。

| 子产品 | 定位 | 计费 | 何时用 | 关键参数 / 坑 |
|---|---|---|---|---|
| **关键词推广** | 手动选词、可控性最强 | CPC | 想拿**搜索词报表**、做否词、精细优化；智能计划的唯一解药 | 3 层词矩阵（核心20%/长尾50%/竞品30%）；新词从行业均价 70–80% 起步 |
| **智能化推广** | 系统自动选品选词 | CPC | SKU 多、没精力逐个调 | ⚠️**关键词报表为 0 条 → 永远无法否词**；47 个 SKU 混投会稀释预算 |
| **全店商品推广** | 全店 SKU 一起投 | CPC | 铺量、测品 | 预算容易跑不满，需主动提预算；CPC 通常最低 |
| **全站智能推广** | 跨搜索+推荐场景托管 | CPC | 新品冷启动、懒人托管 | 出价失控风险（实测出现过 CPC ¥15）；必须盯日报 |
| **新品推广** | 新品期加权 | CPC | 上架 30 天内 | 与主计划错开，别重复投同一 SKU |
| **新客转化** | 定向店铺新客 | CPC | 拉新指标压力大 | 与 DMP「未购买人群」配合 |
| **品牌追击** | 竞品/品牌词拦截 | CPC | 有明确竞品时 | 创意不得贬低竞品、不得用对方商标 |

### 快车必做三件事
1. **3 层关键词矩阵**：核心词 20%（精确/短语）＋ 长尾词 50%（短语/精确，CPC 仅大词 1/3，主力订单）＋ 竞品词 30%（短语+抢位）。
2. **冷启动别一上来开智能**：先手动精确词跑出转化样本（7–15 天），再放量；单计划 SKU ≤ 20。
3. **权重激活阈值**：关键词 ≥10 点击、人群包 ≥50 点击、创意 ≥80 点击、单计划/日 ≥30 点击、账户 ≥3 计划且总点击 ≥100。

## 二、推荐场：海投 / 京速推 / 购物触点

| 工具 | 定位 | 计费 | 参数与打法 | 坑 |
|---|---|---|---|---|
| **京东海投** | 全店智能托管，铺量动销 | CPC/CPM | 新计划日预算 200–300，周期 ≥7 天；定向「近7天浏览+加购」并**排除已购**；展位优先搜索结果页+商品详情页 | 别同时开「自动拓量+全量人群」；24h 内调价 >2 次重置学习期；素材 CTR<1.2% 下掉 |
| **京速推** | 一键智能，货品加速 | CPC/CPM | 选高转化商品（主图清晰、标题含词、价格有竞争力）；目标选「曝光/点击」或「货品加速」 | 推广前查库存防断货；避免盲目提价 |
| **购物触点** | 推荐场景再营销收割 | CPC | 智能出价：日耗目标 200，CPC 上限托管；手动：基础出价行业 70%，购物前 10%/中 20–30%/后 10%，黄金展位 15% | 主用途是**定向加购未付、浏览未购做收割**，不是拉新 |

## 三、品牌场：京东展位 / 品牌合约

| 工具 | 定位 | 计费 | 门槛 | 说明 |
|---|---|---|---|---|
| **京东展位**（原品牌聚效） | 大曝光展示广告 | CPM | 预算门槛较高 | 首焦、频道页等大资源位；适合大促蓄水与心智，不直接看 ROI |
| **品牌合约** | 包断资源位 | CPT/CPM | 大客户/品牌方 | 需提前排期采购；**自营供应商一般无直接权限**，需品牌方或采销牵头 |
| **品牌广告**（搜索品专） | 搜索品牌专区 | CPT | 有商标与品牌资质 | 周郎中若做品牌专区，需商标资质齐全 |

> **供应商提示**：品牌场多需品牌方/采销协同，供应商单独开不了。若店铺主打单品 ROI，优先级应放在搜索场与推荐场。

## 四、站外场：京东直投 / 京挑客 / 京东联盟

| 工具 | 定位 | 计费 | 打法 | 适用 |
|---|---|---|---|---|
| **京东直投** | 站外引流（腾讯社交、巨量引擎、百度、快手） | CPC/OCPM | 用京东 DMP 人群包回传站外定向；素材要适合信息流（前 3 秒抓人） | 拉新客、补搜索场流量不足 |
| **京挑客** | 站外 CPS 推广 | **CPS（成交才付费）** | 设佣金比例（类目常见 10–30%），推高佣金冲量 | **0 曝光风险，适合冲量与清库存**；注意佣金计入成本再算保本 |
| **京东联盟** | CPS 联盟 | CPS | 同上，覆盖面更广 | 长尾持续出单 |

> **消字号注意**：站外投放的素材同样受合规约束（不能用治疗/消炎/抗菌），且站外审核更严。

## 五、内容场：直播 / 短视频 / 逛 / 京任务

| 工具 | 定位 | 说明 |
|---|---|---|
| **京东直播** | 实时转化 | 大促爆发与清货；需排期与主播资源 |
| **短视频 / 逛·发现好货** | 内容种草 | 场景化展示（家庭常备、居家随身），**不得疗效化** |
| **京任务内容种草** | 达人内容投放 | 达人笔记/视频，按任务结算 |

> 内容场对消字号的价值：**建立场景认知**（家庭常备、草本护理），而非讲功效。

## 六、活动场：秒杀 / 9.9 / PLUS / 品牌日 / 会场

| 资源 | 特点 | 供应商如何拿到 |
|---|---|---|
| **京东秒杀** | 限时限量、爆发强 | **采销提报**，需价格与库存支持；毛利要先算清 |
| **9.9 特卖** | 低价走量 | 采销提报；适合低价引流品 |
| **PLUS 会员日** | 高质人群 | 采销/品牌提报 |
| **品牌日 / 品类会场** | 大流量坑位 | 需品牌方与采销对齐 |
| **京东健康会场** | 医药健康类目 | 消字号外用抑菌的**类目主场**，优先争取 |

> **自营供应商的现实**：活动场资源 **不由供应商自主报名**，走采销提报。能做的是：提前备好素材、算好活动价毛利、保证 12 仓库存。

## 七、私域场：会员 / CRM / 券（复购与客单）

| 工具 | 用途 |
|---|---|
| **店铺会员 / 会员通** | 入会礼、会员专享价，沉淀可触达人群 |
| **粉丝群 / 关注** | 新品与活动触达 |
| **京麦 CRM / 短信 / 咚咚** | 老客召回、加购未付提醒 |
| **店铺券 / 神券** | 券面额与门槛设计（**按件数设的多件优惠才归供应商**；满元减多为平台级） |

> ⚠️ 供应商视角：整店满减、跨店满减归平台；供应商能自主的是**自有 SKU 的多件优惠（第 2 件半价 / 满 2 件减）**——按**件数**设门槛，按金额设会把优惠漏给别家商品。

## 八、数据场：DMP / 数坊 / 商智

| 工具 | 用途 |
|---|---|
| **DMP** | 建人群包（浏览未购、加购未付、竞品人群、老客唤醒），做溢价与排除 |
| **京东数坊（4A）** | 人群资产总量与流转（Awareness→Advocacy），品牌向 |
| **京东商智** | 行业/竞品/关键词/商品销售排行数据（**选品与标题挖词的底座**） |
| **京准通报表中心** | 账户/计划/单元/创意/关键词/商品/人群维度报表 |

**DMP 四层人群漏斗**

| 层 | 圈选 | 溢价 |
|---|---|---|
| 高潜人群 | 类目浏览/加购/收藏未购 | 30–50% |
| 竞品人群 | 竞品品牌/店铺标签 | 中 |
| 复购唤醒 | 老客 180 天未回购 | — |
| 排除人群 | 已购本品 | 排除，免浪费 |

## 九、智能出价体系（跨工具通用）

| 模式 | 说明 | 坑 |
|---|---|---|
| 手动 CPC | 完全可控 | 费人力 |
| 最大化成交（OCPX） | 系统按转化出价 | 需足够转化样本 |
| **目标 ROI 控制** | 设投产比目标托管 | ⚠️ 开启后**人群溢价与分时折扣系数失效**（仅「不投放」开关仍生效）——想靠人群分层提投产就别同时开 |
| 一键起量 | 短期放量 | 容易拉高 CPC，盯紧 |

## 十、归因与口径（算投产前必读）

```
数据口径：推广点击 15 天内累计的成交订单
订单行     = 订单中包含该推广商品的行（不是整单）
直接订单   = 广告商品自身成交
间接订单   = 同订单中其他商品（光环效应，自营口径下可能属于别的供应商）
投产比     = 订单金额 ÷ 花费            ← 前台零售价口径
真实投产   = 后台投产比 × 供货价率        ← 供应商口径
保本前台投产比 = 1 ÷ (供货价率 × 毛利率)
```

**报表中心可用维度**：`https://jzt.jd.com/report/#/rtb/basic/{account|campaign}`（商品维度 tab 为自定义组件，脚本点不动 → 从计划详情页进 `msa/#/list/smart/levelTwo?campaignId=...` 看 47 品明细）。

## 十一、工具组合策略（按目标）

| 目标 | 主力工具 | 辅助 | 预算分配建议 |
|---|---|---|---|
| **提投产（当前周郎中首要）** | 快车关键词计划（手动，可拿词报表/否词） | 购物触点收割加购未付 | 搜索 60% / 推荐 25% / 收割 15% |
| **冲量动销** | 海投 + 京速推 | 京挑客 CPS | 托管 50% / CPS 30% / 搜索 20% |
| **新品冷启动** | 快车新品推广 + 手动精确词 | 全站智能小预算 | 新品 70% / 托管 30% |
| **清库存** | 京挑客高佣 + 秒杀 | 站外直投 | CPS 60% / 活动 40% |
| **大促爆发** | 秒杀/会场 + 快车提价 + 分时系数拉满 | 海投全站智能 | 活动 40% / 搜索 40% / 推荐 20% |

## 十二、周郎中当前的工具缺口（2026-10 快照）

- ✅ 在用：快车（智能化 2 条、全店推广、全站智能 2 条、关键词 2 条）
- ❌ 未用：海投、京速推、购物触点、京东展位、直投、**京挑客 CPS**、内容场、私域券
- **优先级建议**：① 京挑客（0 曝光风险，CPS 成交才付费）② 购物触点（收割 310 个加购未购）③ 海投小预算测铺量
