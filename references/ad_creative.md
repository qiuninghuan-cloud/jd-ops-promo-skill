# 推广创意图优化 SOP（CTR × CVR 双指标）

> 推广主图（京准通创意图）≠ 商品主图。商品主图服务自然流量，创意图服务**广告位**——
> 它同时受《广告法》和平台广告审核约束，比自然商品图更严。
> 本文件讲"广告图怎么做得更会点、点了更会买"。

## 〇、先分清三种创意形态

| 形态 | 是什么 | 谁控制 | 适用 |
|---|---|---|---|
| **商品主图** | 自动拉取在售商品的首图 | 商品端（见 `main_image.md`） | 快车默认；图烂就没得选 |
| **自定义创意图** | 单独上传的广告图，可带卖点文案 | 投放端，**你能自主** | 购物触点/推荐位主力；快车辅助 |
| **智能创意** | 系统自动拼接图 + 标题片段 | 算法 | 海投/京速推；**必须人工审拼接结果** |

**智能创意的坑**：系统会把在投标题（可能含违规词）和你的图自动拼成新组合。
你自己审过标题和图都没用——**拼接结果要单独审**，拼出"硫磺膏+私处"这种组合就是审核事故。

## 一、各位置创意规格（投放前必查后台当日提示）

| 投放位置 | 创意形态 | 要点 |
|---|---|---|
| 快车·搜索位 | 商品主图为主，可加自定义 | 创意图案含投放关键词（搜索结果里与搜索词呼应，CTR 明显更高） |
| 购物触点·推荐位 | 自定义创意图为主 | 无搜索意图，靠场景/痛点/利益点抓停留 |
| 京速推/海投 | 智能创意为主 | 人工审拼接；劣质及时关智能换自定义 |
| 大促焦点图 | 按活动模板 | 走采销/活动提报，不自主 |

> 尺寸/大小/张数规则京准通常更新，**以后台创建设计页当日提示为准**，本文件不写死数值。

## 二、提 CTR：创意四手法

1. **图上带字，带"对的话"**：推荐位用户没有搜索意图，图上一行字决定停不停——
  数字（30g 大容量）、场景（居家常备）、利益点（家庭装更划算）三选一，别都上。
2. **创意与搜索词呼应**：投"皮肤抑菌膏"的单元，创意图上出现"抑菌"相关字，
   搜索列表里用户视线会优先落过去（相当于飘红效果的图片版）。
3. **按人群换创意**：同一 SKU 对不同人群说不同话——
  新客/泛人群讲"是什么"（草本外用抑菌），加购未购讲"为什么现在买"（家庭装更划算）。
   一条创意打所有人群，CTR 必然被平均下来。
4. **价格利益点如实呈现**：可以讲"多件装单价更低"这类客观事实；
   禁"全网最低/史上最便宜"（广告法绝对化用语，创意图比商品图查得更狠）。

## 三、提 CVR：承接一致性（比图本身更重要）

**高 CTR 低 CVR 的第一嫌疑人不是图，是落地承接。**

| 检查项 | 规则 |
|---|---|
| 创意承诺 = 主图承诺 = 详情页 | 三处不一致 = 用户预期落差，跳失率飙升 |
| 创意推的品 = 落地页的品 | 创意推苗草癣，落地到紫草膏 = 白烧点击 |
| 创意图案 = 单元 SKU | 自定义创意图挂错 SKU 是低级但高发的浪费 |
| 价格感知一致 | 创意图暗示"便宜"，落地看到 ¥55，直接走人 |

诊断顺序：CTR 低 → 先换创意；CVR 低 → **先查承接一致性，再查人群精准度**，最后才怀疑品。

## 四、消字号创意图红线（广告法 + 平台双重审核）

| 禁止 | 说明 |
|---|---|
| 绝对化用语 | 最 / 第一 / 国家级 / 根治 / 100%——广告法明令，创意图严打 |
| 疗效暗示 | 前后对比图、病灶图、见效时间（"三天"） |
| 医疗符号 | 白大褂、听诊器、十字、处方 Rx |
| 贬低他人 | 拉踩竞品、用对方商标 |
| 无依据数据 | "99% 用户好评"类无出处数字 |

> 与商品主图共用的红线见 `main_image.md` 第六节；本节是**广告位加严部分**。

## 五、测图纪律（和商品主图测法相同，标准不同）

- **每计划挂 3–5 个创意**（超过 5 个预算被摊薄，测不出显著性）。
- **点击量门槛是经验起始值，不是平台淘汰标准**：≥80 点击再判优劣——低于此样本量，CTR 波动主要是噪声不是差异。
  实际执行以**本品类/本品计划的历史 CTR 基线**为准：先跑出账户或计划的基线 CTR 再定淘汰线；
  点击量不够时**延长观察期**，而不是硬砍（小预算计划可能一周都到不了 80 点击）。
- **判据**：CTR 明显低于基线的创意淘汰（**1.2% 是早期经验值，非通用规则**）；保留 TOP 创意当"对照组"，每次只换一个新变量。
- **创意疲劳**：同一创意连续跑 2–3 周后 CTR 自然衰减，届时换新，不是品出了问题。
- 淘汰节奏：每周固定一天看创意报表，劣质创意下线、补 1 个新创意（周淘汰，见 `promo.md`）。

## 六、创意数据在哪看

京准通 → 报表中心 → **创意维度报表**：展现 / 点击 / CTR / 花费 / 成交 / ROI 按创意拆。
这是唯一能回答"哪张广告图在赚钱"的报表，**每周必看**。

> 供应商口径提醒：创意报表的成交金额同样是**订单行口径（前台 GMV）**，
> 真实投产 = 该创意的后台 ROI × 供货价率。某创意 CTR 高但真实 ROI 低 → 它在拉来不赚钱的点击。
