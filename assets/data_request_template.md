# 缺数据 · 结构化追问单

> 用途：诊断/方案类任务缺关键数据时，**一次性、结构化**地向用户索取，替代"建议补充数据"式的含糊。
> 用法：复制下方表格，勾选本次真正卡住的项发出；拿到后回填并据此更新结论置信度。
> 纪律：能算的先用区间给结论并标"待核"，只问真正会改变结论的项——不要让用户填一堆无关字段。

## 取数完整性自检（六查，对每次导出都做）

1. **分页完整性**：导出是否含全部页（末页行数 ≠ 页大小即疑漏）。
2. **SKU 去重**：同编码多行先按编码去重再汇总。
3. **汇总对账**：Σ 各计划成交 ≈ 账户汇总，对不上先查再算。
4. **退款净额**：成交金额是否已扣退款/退货。
5. **归因回补**：点击后 N 天归因窗口内的成交会后续回补，跨日/跨周必须固定同一窗口。
6. **跨渠道重复**：同一次成交是否被多个渠道/计划重复统计。
