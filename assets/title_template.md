# 京东标题撰写模板（填入即用）

> 用法：复制下方结构，按 SKU 填词，词块间用空格分隔。填完用 `scripts/check_title.py` 校验。

## 结构公式
```
[品牌词] + [核心词] + [规格] + [属性词] + [合规功效词] + [成分/配方词] + [场景词] + [人群/部位词]
```

## 填空位
- 品牌词：周郎中
- 核心词：__________
- 规格：__________（如 30g）
- 属性词：__________（如 草本 / 植物配方）
- 合规功效词（仅限 抑菌/清洁/护理 类）：__________
- 成分/配方词：__________（如 紫草 / 植物萃取）
- 场景词：__________（如 家庭常备 / 居家外出）
- 人群/部位词：__________（如 成人 / 肌肤 / 口腔）

## 产出标题（草稿）
```
周郎中 [核心词] [规格] [属性词] [合规功效词] [成分词] [场景词] [人群词]
```

## 候选标题 A（主推，品牌+核心+性价比）
```
周郎中 紫草皮肤抑菌膏 30g 草本植物配方 外用抑菌 温和不刺激 家庭常备 居家护理
```

## 候选标题 B（长尾，覆盖成分搜索）
```
周郎中 紫草膏 30g 植物萃取 外用抑菌 易吸收不黏腻 日常护理 成人可用
```

## 候选标题 C（场景，覆盖家庭/便携搜索）
```
周郎中 皮肤抑菌膏 30g 草本温和 外用洁净 家庭常备 随身便携 居家外出
```

> 每个候选须过 `scripts/check_title.py`，零命中禁用词、汉字数 ≤ 30。
