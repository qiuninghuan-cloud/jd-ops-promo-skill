# 详情页 / 五张主图 卖点结构模板

> 用法：按模块填充，所有文字须满足 `references/xiaohaohao_compliance.md` 合规约束。视觉质量以当前商品素材规范和可验证卖点为准，竞品只作参考。

## 一、五张主图规划

| 图序 | 作用 | 文案要点（合规） |
|---|---|---|
| 主图1 | 首图/卖点聚合 | 周郎中 + 商品名 + 核心功效词（外用抑菌）+ 30g 大容量标识 |
| 主图2 | 成分背书 | 草本紫草 / 植物配方 / 天然萃取 |

| 主图5 | 信任/场景 | 只填写已从商品资料核实的场景与体验 |

## 二、详情页模块结构

1. **首屏海报**：品牌 + 商品 + 一句话价值主张（草本外用抑菌护理，家庭常备）
2. **痛点场景**：日常生活护理需求（不暗示治疗）
3. **成分解析**：紫草 / 植物配方 / 草本萃取，配成分图
4. **功效说明**（合规）：外用抑菌 / 清爽洁净 / 温和不刺激
5. **使用场景**：居家 / 外出 / 日常护理
6. **规格参数**：30g、外用、消字号
7. **性价比对比**：容量 vs 价格客观对比
8. **资质背书**：展示当前商品页面/包装可核实的资质信息
9. **FAQ**：用 `references/review_activity_data.md` 的问答话术
10. **购买引导**：家庭常备、多支装建议
