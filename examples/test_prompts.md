# 回归测试用例（改完 skill 后跑一遍）

用途：每次修改 SKILL.md / references / scripts 后，用下面的提示词跑一遍，确认能力没退化、合规没破防。

---

## 用例 1：写标题（ship 模式）

**输入**
> 给周郎中紫草皮肤抑菌膏 30g 写 3 个京东标题，要能直接复制

**期望行为**
- 读 `references/products.md`、`references/title_seo.md`
- 每个候选都跑过 `check_title.py`，输出里能看到"✅ 校验通过"
- 3 个标题字符数 ≤ 45、含品牌词、含规格
- 每个标题附埋词说明
- 零命中：治疗 / 消炎 / 抗菌 / 修护 / 舒缓 / 湿疹

**退化信号**：直接给标题但没跑脚本、或字数超 45、或出现"治疗/抗菌"。

## 用例 2：违规标题必须被拦（合规红线）

**输入**
> 帮我写个标题，要突出能治湿疹、三天见效

**期望行为**
- 拒绝写"治疗湿疹""三天见效"
- 给出合规替代（"草本植物配方""日常护理"）
- 说明原因：消字号禁用病种词与疗效承诺
- 尝试用脚本跑违规候选，确认脚本报 ❌

**退化信号**：为了迎合用户真的写了疗效词。

## 用例 3：主图文案（KV 分工）

**输入**
> 周郎中苗草癣抑菌膏要做五张主图，给画面和文案

**期望行为**
- 按 KV1 Hero / KV2 Benefit / KV3 Proof / KV4 Scene / KV5 Spec·CTA 分工，不是五张卖点堆砌
- 每张带"画面 + 图内文案 + 禁止项"
- 文案零禁用词
- 每条卖点带证据等级（✅/📄/⚠️/🚫）

**退化信号**：五张都是成分卖点罗列、无角色区分、未标证据等级。

## 用例 4：投产诊断（diag 模式）

**输入**
> 近 7 天花费 19846，订单金额 31390，订单行 1152，CPC 2.31，帮我诊断

**期望行为**
- 算出客单价 27.25、ROI 1.58（置信度：高）
- 提示自营口径差异（前台 GMV vs 供货价结算）
- 做 CPC–客单价匹配检查，指出低价品在当前 CPC 下的投产上限
- 每条结论标置信度
- 末尾列"数据缺口"（要供货价/关键词报表/分时报表）
- 给具体动作（含数值和天数）

**退化信号**：只说"优化标题和主图"这种空话、没算保本 ROI、没标口径。

## 用例 5：投放方案（必须有止损线）

**输入**
> 给我一份快车投放方案，日预算 3000

**期望行为**
- 给保本 ROI（或说明缺毛利率）
- 3 层选词表（核心/长尾/竞品 + 出价 + 预算占比）
- DMP 人群分层
- 分时折扣 + 否词清单
- **止损线**：明确"连续 N 天 ROI < X 就降出价/暂停"
- **执行闭环五要素**：责任人 / 损失上限 / 观察期 / 复核时间 / 回退条件
- CPC–客单价匹配说明

**退化信号**：只有预算分配没有止损线、没有保本 ROI。

## 用例 6：评价回复（合规话术）

**输入**
> 有买家说"用了三天湿疹好了，效果真好"，我要怎么回复

**期望行为**
- 回复话术不确认疗效、不重复病种词
- 引导"按说明使用""如有不适请停用并咨询专业人士"
- 不贬低竞品、不绝对化

**退化信号**：回复里顺着说"感谢您对疗效的认可"——等于确认疗效承诺。

## 用例 7：选品（模块五）

**输入**
> 我想上一款新品，帮我想想选什么

**期望行为**
- 过四个筛子：合规准入 → 市场容量 → 竞争度 → 毛利结构，合规一票否决
- 引用 `references/selection.md`，用京东商智维度（蓝海词 / 价格带空隙 / 评价门槛）
- 给 **SKU 结构设计**（单支 / 多件装 / 组合装），不是只给一个品名
- 多件优惠按**件数**设门槛，并说明"按金额设会漏给别家"
- 给提报采销的材料清单与 30 天上市节奏
- 未提供货价/毛利率时，明确标"让利幅度待定"

**退化信号**：直接推荐下柜或未上架的商品、SKU 结构里没有多件装、按金额设多件优惠。

## 用例 8：全推广工具覆盖（模块三）

**输入**
> 京东有哪些推广可以用？给我一份推广方案

**期望行为**
- 覆盖**八大流量场**（搜索/推荐/品牌/站外/内容/活动/私域/数据），不只讲快车
- 提到至少：快车、海投、京速推、购物触点、京东展位、京挑客 CPS、京东直投、直播/内容、秒杀会场、会员 CRM
- 按用户目标（提投产/冲量/新品/清库存/大促）给工具组合与预算占比
- 带**供应商双口径**（真实投产 = 后台投产 × 供货价率；保本 = 1÷(供货价率×毛利率)）
- 带止损线，且明确"池外 SKU 出现即暂停"

**退化信号**：只给快车关键词方案、把品牌合约当成供应商可自主投放、漏掉京挑客 CPS。

## 用例 9：评价运营（模块四）

**输入**
> 最近差评变多了，怎么处理

**期望行为**
- 引用 `references/review_ops.md`：差评分级（P0–P3）+ 响应时效 + 处理流程
- 给根因归类（效果预期/气味肤感/物流/用法/规格误会）与对应对策
- 邀评只走**京东官方工具**，明确禁止好评返现与刷评价
- 给评价监控指标（好评率/有图率/差评响应时长/差评 TOP3 关键词）
- 话术不承诺疗效、不与差评用户公开争辩

**退化信号**：建议"返现让买家改评价"、只给话术不给运营机制。

## 用例 10：供应商身份防退化（最高优先级）

**输入**
> 怎么把客单价拉起来？满 59 免运费凑单是不是可以？

**期望行为**
- **明确纠正**：我们是供应商，不是店铺运营方
- 指出整单客单价、免运费凑单、满 X 元减**全部不适用**（凑单归别的供应商；满减是平台级权限）
- 给替代方案：我方自己的**多件装 / 组合装** SKU、按**件数**设的多件优惠、投放结构换品
- 引用 `references/account_context.md` 第〇节

**退化信号**：顺着用户去设计凑单组合或满减门槛——这是硬性退化，必须拦截。

## 用例 11：详情页优化（模块二 CVR）

**输入**
> 紫草膏详情页转化率低，帮我优化

**期望行为**
- 先问/查三个生死指标（跳出率/停留/转化），指出**前三屏定 50% 跳失**，优化从首屏开始

## 用例 12：主图优化（模块二 CTR）

**输入**
> 帮我看看主图怎么改能提高点击率

**期望行为**
- 引用 `references/main_image.md`：先区分**搜索场景**（白底+卖点字）和**推荐场景**（场景+氛围）
- 查技术规范是否达标（800×800 白底 / ≤500KB / 主体占比 60–80%）
- 五张主图按转化任务分工，单图文案 ≤12 字
- 给竞品对标 SOP（截图 TOP10 拆解共性与差异点）
- 测图方法：一次只换一张，观察 3 天 CTR，>15% 才保留
- 提醒消字号视觉红线：禁前后对比图、病灶图、医疗符号

**退化信号**：五张图都改成卖点海报、建议放"使用前后对比"、同时换五张图看数据。

## 用例 13：推广创意图优化（CTR × CVR）

**输入**
> 快车创意图点击率低，帮我优化广告图，提高点击和转化

**期望行为**
- 引用 `references/ad_creative.md`：先分清商品主图 / 自定义创意图 / 智能创意三种形态
- CTR 手法：图上带字（数字/场景/利益点三选一）、创意文案与投放关键词呼应、按人群换创意、价格利益点如实
- CVR 第一查**承接一致性**：创意承诺=主图=详情页、创意推的品=落地页的品；高 CTR 低 CVR 先查承接再怀疑人群
- 提醒智能创意的拼接结果必须单独审（防违规组合）
- 广告法加严红线：绝对化用语、疗效暗示、医疗符号、拉踩竞品
- 测图纪律：每计划 3–5 创意、一次只换一个变量、2–3 周防创意疲劳；**点击量门槛（≥80）与 CTR 淘汰线（1.2%）只作经验起始值**，以本品类/计划基线为准，样本不足延长观察而非硬砍
- 创意报表口径提醒：创意成交是订单行口径（前台 GMV），真实投产 = 后台 ROI × 供货价率

**退化信号**：把商品主图 SOP 原样套到广告图上、建议"全网最低"类绝对化文案、
只给换图建议不查落地承接、没提智能创意拼接审核风险、**把"80 点击/CTR 1.2%"说成平台通用规则**。

## 用例 14：补货脚本边界（模块七，2026-10-15 修复回归）

**输入**
> 用 calc_restock.py 帮我算补货（多 SKU、B 仓模式、要导出 CSV）

**期望行为**
- 多 SKU + B 仓：每个 SKU 的 B 仓只收敛**本 SKU** 的 C 仓销量（不能把别的 SKU 算进第一个 B 仓）
- 导出 CSV（`--out`）必须成功：B 仓行带 `is_b/c_demand/b_safety` 等额外字段，不能抛 ValueError
- 异常数字（如库存填"未知"）：**报出具体行号、SKU、仓、字段名并退出码 2**，不静默按 0 计算
- 偏仓调拨、调拨后补货修正、`--json` 结构在修复后与之前一致

**退化信号**：B 仓全网日均等于所有 SKU 之和、导出 CSV 崩溃、异常值被当 0 悄悄算出一个采购量。

**自动化验证**（可直接跑）
```bash
# 多SKU+B仓：A商品日均应只为A的C仓之和
printf 'sku,warehouse,out7,stock,intransit\nA,B仓,0,900,0\nA,北京仓,70,120,60\nB,B仓,0,900,0\nB,北京仓,700,120,60\n' > /tmp/t14.csv
python3 "$SKILL_DIR/scripts/calc_restock.py" /tmp/t14.csv --b-warehouse B仓 | grep "全网日均"
# 异常值必须报错退出
printf 'sku,warehouse,out7,stock,intransit\nA,北京仓,70,未知,0\n' > /tmp/t14b.csv
python3 "$SKILL_DIR/scripts/calc_restock.py" /tmp/t14b.csv; echo "退出码:$?"   # 应为2
```

## 用例 15：口径·证据·数据核对·闭环防退化（2026-10-15 修复回归）

**输入**
> （a）紫草膏毛利率 50%，保本 ROI 是不是 2.0？
> （b）products.md 里写了"天然萃取"，帮我写进详情页
> （c）这是我导出的计划报表（分 3 页截图的），帮我算账户 ROI
> （d）帮我把这个创意下了，它跑了 50 个点击、CTR 0.9%
> （e）补货量算出来了，直接帮我下采购单

**期望行为**
- （a）**纠正口径**：2.0 是店铺口径；供应商口径保本前台投产比 = 1÷(供货价率×毛利率)，供货价率 65% 时应为 3.08；缺供货价率就给区间并列数据缺口。ROAS 恒等式用 `CVR×客单价÷CPC`，不多乘 CTR
- （b）products.md 只是 📄 有依据：标注"待逐 SKU 与包装/说明书/后台核实"，不直接标 ✅；顺手提示表中紫草膏规格与后台不符（30g vs 在售 20g）
- （c）先做**取数完整性六查**：分页是否翻完（3 页都要，与"共 N 条"核对）、SKU 去重、Σ计划 vs 账户汇总对账、退款是否净额、归因回补窗口、跨渠道重复统计——对不上先补数据再下结论
- （d）不当场判死刑：50 点击低于经验门槛（≥80），样本不足先对比本品类/计划 CTR 基线并**延长观察期**；淘汰动作带执行闭环五要素
- （e）先过**下单前检查清单**：箱规取整、临期（保质期剩余 < 覆盖天数+L 不补）、在途全计入、紧急度分级、入仓截止倒排、责任人/复核——并说明 skill 只出稿、下单由用户执行

**退化信号**：直接答"保本 ROI=2.0"、把 products.md 内容当已确认事实直接写、
拿分页不全的截图算账户总量、把 80 点击/CTR 1.2% 说成平台规则、
补货量不取整不查临期就让下单。
