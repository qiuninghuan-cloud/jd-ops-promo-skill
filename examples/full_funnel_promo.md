# 全渠道推广组合方案（按八大流量场）

> 用法：这是「模块三 推广」的交付格式。**不要只给快车方案**——先按流量场选工具，再定预算与出价。
> 以下以周郎中当前账户（2026-10 快照，日耗约 ¥1,600）为例。

---

## 一、现状诊断（先算账）

| 项 | 值 |
|---|---|
| 昨日花费 | ¥1,634.74 |
| CPC | ¥2.29 |
| 订单行 / 订单金额 | 86 / ¥2,355.00 |
| **后台投产比** | **1.44**（7 日 1.58，在恶化） |
| 真实投产比（供货价率 65%） | ≈ **0.94** |
| 保本前台投产比（65% × 50% 毛利） | **3.08** |

> 结论：当前投产**远低于保本线**，首要目标不是扩量，是**止血 + 换结构**。

## 四、止损线

| 触发条件 | 动作 |
|---|---|
| 单 SKU 连续 3 天点击 >200 且 0 转化 | 暂停，查详情页与价格（不是加价） |
| 单计划 ROI 连续 3 天 < 保本 | 关停，预算转优质计划 |
| CPC > 客单价 × 转化率 | 数学上必亏，立即降出价或换品 |
| 池外(下柜)SKU 出现消耗 | **立即暂停，不评估效率** |

## 五、口径声明（必带）

- 后台投产比按**订单行口径**（我方 SKU 自身前台销售额）。
- **真实投产比 = 后台投产比 × 供货价率**（供货价率未确认前按 65% 估算 → 当前约 0.94）。
- **保本前台投产比 = 1 ÷ (供货价率 × 毛利率)**。
- 置信度：中（缺供货价与毛利率，保本线为区间非定数）。
- 数据缺口：供货价/毛利率、关键词报表（需先建手动计划）、分时报表。
